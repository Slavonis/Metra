# Анализатор метрик Холстеда для кода JavaScript

Программа-парсер на **C# (.NET 8)** с **графическим интерфейсом (Avalonia)**.
Она выполняет лексический и синтаксический анализ исходного кода на языке
**JavaScript** и рассчитывает **метрики Холстеда**: 6 базовых и 3 расширенные
(производные), в соответствии с Примером 1 из методических материалов
(«Метрики размера программ»).

---

## 1. Состав проекта

```
HalsteadAnalyzer.sln
├─ src/
│  ├─ HalsteadAnalyzer.Core/     ← ядро: лексер + анализатор (без зависимостей)
│  │   ├─ Token.cs               ← лексема
│  │   ├─ JsTokenizer.cs         ← лексический анализатор (сканер) JavaScript
│  │   ├─ HalsteadCalculator.cs  ← классификация операторов/операндов + метрики
│  │   └─ HalsteadResult.cs      ← модель результата
│  ├─ HalsteadAnalyzer.Gui/      ← графический интерфейс (Avalonia)
│  └─ HalsteadAnalyzer.Cli/      ← консольный вариант (для проверки/отчёта)
└─ tests/
   ├─ small.js                   ← маленький тестовый файл (25 строк)
   └─ large.js                   ← большой тестовый файл (98 строк, 90–100)
```

Ядро (`Core`) не зависит ни от чего, кроме стандартной библиотеки .NET, и
используется как графическим интерфейсом, так и консольной утилитой.

## 2. Требования

* **.NET SDK 8.0** или новее — https://dotnet.microsoft.com/download
* Для графического интерфейса дополнительно ничего ставить не нужно: пакеты
  Avalonia скачиваются автоматически при первом запуске (`dotnet restore`).

```bash

```

## 3. Запуск графического интерфейса

### macOS / Linux

```bash
cd HalsteadAnalyzer
dotnet run --project src/HalsteadAnalyzer.Gui
```

### Windows

```powershell
cd HalsteadAnalyzer
dotnet run --project src\HalsteadAnalyzer.Gui
```

либо откройте `HalsteadAnalyzer.sln` в Visual Studio / Rider, выберите проект
`HalsteadAnalyzer.Gui` как стартовый и нажмите «Запуск».

### Как пользоваться

1. Нажмите **«Открыть .js файл…»** и выберите `tests/small.js` или
   `tests/large.js` (или любой свой файл), либо нажмите **«Загрузить пример»**,
   либо просто вставьте код в левое поле.
2. Нажмите **«Анализировать»**.
3. Справа появятся:
   * **таблица из 6 базовых метрик** — две частотные таблицы
     (операторы: `j / Оператор / f1j`; операнды: `i / Операнд / f2i`) с итогами
     **η1, N1** и **η2, N2**;
   * отдельная панель с **3 расширенными метриками** — **η, N, V**.

## 5. Метрики Холстеда

**6 базовых метрик** (определяются непосредственно при анализе текста):

| Обозначение | Смысл |
|-------------|-------|
| η1 | словарь операторов — число уникальных операторов |
| η2 | словарь операндов — число уникальных операндов |
| N1 | общее число операторов |
| N2 | общее число операндов |
| f1j | число вхождений j-го оператора (столбец таблицы операторов) |
| f2i | число вхождений i-го операнда (столбец таблицы операндов) |

**3 расширенные (производные) метрики:**

| Формула | Смысл |
|---------|-------|
| η = η1 + η2 | словарь программы |
| N = N1 + N2 | длина программы |
| V = N · log₂ η | объём программы (в битах) |

## 6. Модель классификации операторов и операндов для JavaScript

Модель повторяет логику интерпретации Холстеда из методички (где она дана для
Паскаля) и адаптирована к синтаксису JavaScript.

**Операторами** считаются:

* знаки арифметики `+ - * / % **`, инкремент/декремент `++ --`;
* присваивания `= += -= *= /= %= **= &= |= ^= <<= >>= >>>= &&= ||= ??=`;
* сравнения `== === != !== < > <= >=`;
* логические `&& || !`, поразрядные `& | ^ ~ << >> >>>`, `??`;
* тернарный оператор `?` и `:`, стрелка `=>`, расширение `...`;
* пара круглых скобок **`( )`** при выделении подвыражения, в заголовке
  управляющей конструкции (`if (...)`, `for (...)`, `while (...)` и т.п.) и в
  списке параметров функции — **пара считается одним оператором**;
* пара **`[ ]`** (индекс/литерал массива) и пара **`{ }`** (блок/объект) —
  по одному оператору за пару;
* разделители `.` `,` `;` `:`;
* служебные слова-операторы: `if, else, for, while, do, switch, case, default,
  break, continue, return, function, var, let, const, new, typeof, instanceof,
  in, of, delete, void, throw, try, catch, finally`;
* **вызов функции `имя( )`** — считается отдельным оператором, названным по
  имени вызываемой функции (например, `console.log(...)` → оператор `log()`).

**Операндами** считаются:

* идентификаторы — имена переменных, свойств, а также имена объявляемых
  функций;
* литералы: числа, строки, шаблонные строки, регулярные выражения, а также
  `true`, `false`, `null`, `undefined`, `NaN`, `Infinity`, `this`.

**Что игнорируется** (по условию задания):

* содержимое комментариев (`// ...` и `/* ... */`) — не учитывается;
* содержимое строковых и шаблонных литералов, регулярных выражений — сам литерал
  считается **одним операндом**, а его внутренний текст на токены не разбивается;
* метки не относятся ни к операторам, ни к операндам.

### Ключевой нюанс — вызов функции

> Вызов функции сам по себе — это **оператор**. Но если вызов функции является
> **частью выражения** (его результат используется), то имя функции считается
> **и оператором, и операндом**.

Как это определяется программой: вызов считается частью выражения, если его
результат кому-то передаётся — он стоит в правой части присваивания, является
аргументом другого вызова, условием, операндом операции, участвует в цепочке
`.`/`?.`, стоит после `return`, `new` и т.п.

Примеры:

```js
console.log(x);          // вызов-инструкция → только ОПЕРАТОР  log()
sum = sum + factorial(k);// factorial(k) внутри выражения → и ОПЕРАТОР factorial(),
                         //                                  и ОПЕРАНД  factorial
arr.push(line);          // вызов-инструкция → только ОПЕРАТОР  push()
total = compute(a, b);   // compute(...) в правой части → ОПЕРАТОР + ОПЕРАНД
```

## 7. Соответствие Примеру 1 из методички

В методичке для программы на Паскале (вычисление `sin x` через ряд) получено:
η1 = 14, N1 = 33, η2 = 7, N2 = 28, откуда η = 21, N = 61, V ≈ 268.

Данная программа реализует ту же методику подсчёта (таблица операторов и
операндов с частотами, затем η = η1 + η2, N = N1 + N2, V = N·log₂η), но для
исходного кода на **JavaScript**.

### Результаты по прилагаемым тестовым файлам

`tests/small.js` (25 строк): η1 = 17, N1 = 50, η2 = 14, N2 = 35 →
η = 31, N = 85, V ≈ 421,11.

`tests/large.js` (98 строк): η1 = 41, N1 = 239, η2 = 64, N2 = 169 →
η = 105, N = 408, V ≈ 2739,41.

(Значения можно воспроизвести консольной командой из раздела 4.)

## 8. Что демонстрируют тестовые файлы

* **все основные операторы** языка: арифметика, присваивания, сравнения,
  логические и поразрядные операции, тернарный оператор, `if/else`, `for`,
  `while`, `do…while`, `switch/case/default/break`, `return`;
* **пользовательские подпрограммы** — объявления функций (`factorial`,
  `average`, `classify`, `makeStudent`, `isPassing`, …);
* **вызовы функций обоих видов** — как самостоятельные инструкции
  (`console.log(...)`, `arr.push(...)`) и как части выражений
  (`average(s.scores)`, `factorial(k)`, `isPassing(...)`).
